========================
Documentation community
========================

We are bringing together a community around documentation. Communities need a `Third Place`_ to gather, and we hope to be that place. We currently have several places for people to connect:

    * Write the Docs on `Slack`_
    * The Write the Docs `Newsletter`_
    * Write the Docs on `LinkedIn`_
    * Write the Docs on `GitHub`_

Contributing
-------------

A community without people who help maintain standards and advance the state of the art isn't worth having. Write the Docs on `GitHub`_ is the place to contribute to this site and other parts of the community. If you have any wild, odball, mundane, or old-hat ideas, we'd love to consider and appreciate them.
